# Link Medi (MOA) – 거제 조선업 근로자 자세 위험도 · 병원 연계 MVP

PRD·TRD 기반 모바일 우선 정적 웹앱. **자가 설문 → 영상 자세 분석(브라우저 온디바이스 MediaPipe) → 통합 결과 → 본인 선택 → 병원 연계(시뮬레이션) → 재촬영 후 이전 결과와 비교**.

> 의학적 진단이 아닌 참고 정보입니다. 병원 데이터는 예시이며 전송은 시뮬레이션입니다. 영상 원본은 서버로 보내지 않습니다.

## 실행
```
python -m http.server 8000      # http://localhost:8000
```
- 처음 분석 시 MediaPipe(wasm/모델)를 CDN에서 받습니다. 로드 실패 시 화면에 안내와 **다시 시도** 버튼이 나오고, **샘플 데이터(허리·어깨·목)** 로 전체 흐름을 시연할 수 있습니다.
- 정적 파일뿐이라 GitHub Pages / Netlify / Vercel에 그대로 올리면 됩니다(`Settings → Pages → main / root`).

## 테스트
- Node 사용 시: `node tests/run.mjs` (또는 `npm test`)
- Node 없이: 서버 실행 후 http://localhost:8000/tests/index.html → 하단에 `PASS` 표시
- 19개 단위 테스트: 각도 복원, 임계값 경계, 비교 ±10%p 경계·비교 불가 3종, ROM, 신뢰도<60% 처리, 설문 검증/누락 사유, 응급 안내, 병원 필터·정렬, **동의(user click) 없는 전송 차단, 영상 필드 포함 전송 거부**, 영상 형식·길이·용량 검증.

## 오류 처리
- 설문 필수 누락, 동의 미체크, 미지원 형식·길이·용량 → 분석 전 차단 + 사유 표시
- MediaPipe 로드 실패 → 안내 + 다시 시도 + 샘플 체험
- 관절 인식 신뢰도 부족(유효 프레임 <60%) → "신뢰도 낮음", 판정·비교 제외, 재촬영 안내
- 분석 중단 버튼 → 메시지 후 재시도 가능

## 한계 (정직하게)
- 임계값: 허리 20°/60°, 어깨 45°/90°는 TRD 기준, **목 20°/45°는 가정값**. 2D 단일 카메라 추정이라 정확도(Kinovea 대비 MAE ≤7°)는 **아직 검증하지 않음**.
- 병원 데이터·인기순은 예시, 다국어·관리자 화면·실제 병원 연동·서버 저장은 향후 확장.

## 시연 시나리오 (3분)
1. 게스트 체험 → 설문(허리·통증 6) → 2. 작업종류 선택 후 **샘플: 허리** → 3. 결과·"진단 아님" 확인 → 4. 병원 연계 → 항목 선택 → 시뮬레이션 전송 → 5. 다시 촬영(샘플) → 이전 결과와 비교 코멘트.
